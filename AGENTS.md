# Agent instructions

This repository is a scientific review and benchmark project for uncertainty quantification in deep learning.

- Read [PROJECT_BRIEF.md](PROJECT_BRIEF.md) before project work. It is the canonical source for purpose, scope, commitments, and collaboration rules. Read its linked benchmark notes and resource inventory when relevant to the assignment.
- Work on one bounded assignment at a time. State its scope, expected scale, output, and stopping point; an already scoped user request is sufficient agreement. Complete necessary work and checks within that scope, then return for discussion. Wait for agreement on the next step, including within the same roadmap stage. Routine actions within the assignment do not need repeated confirmation.
- A broad request to start the project selects the brief's **First agentic run: literature orientation**. Deliver that initial orientation with visible evidence gaps; deeper review, shortlist selection, and implementation follow in later agreed assignments.
- Preserve core commitments, follow current working agreements until revised, and improve provisional designs as evidence develops. Record substantive revisions and their rationale. Discuss changes to scope, inference target, resource allowance, or deliverables before acting on them.
- Defer the new method's algorithmic details until the user is ready to integrate it. The literature review and existing-method benchmark can proceed independently.
- Preserve claim-to-source and result-to-run provenance. Apply the brief's source-verification requirements and distinguish published findings, reproduced results, and interpretations.
- Keep project files in this repository. Agents run locally; the user schedules cluster jobs from the reproducible packages the agent prepares.
- Update `PROGRESS.md` at research/development checkpoints with artifact paths, completed work, decisions and their rationale, open questions, and the proposed next step. Keep the brief and supporting documents consistent with agreed revisions.
