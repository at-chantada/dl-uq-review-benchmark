# Agent instructions

This repository is a scientific review and benchmark project for uncertainty quantification in deep learning.

- Read [PROJECT_BRIEF.md](PROJECT_BRIEF.md) before project work. It is the canonical source for scope, scientific requirements, resources, and the roadmap.
- Follow the user's current task and agreed stage. For the initial research run, follow the brief's **First agentic run** section and return with its artifacts for discussion before advancing stages.
- Keep agreed requirements distinct from sections marked **proposed**. Do not silently treat tentative numerical settings or candidate methods as final decisions.
- Defer the new method's algorithmic details until the user is ready to integrate it. The literature review and existing-method benchmark can proceed independently.
- Preserve claim-to-source and result-to-run provenance. Apply the brief's source-verification requirements and distinguish published findings, reproduced results, and interpretations.
- Keep project files in this repository. Agents run locally; the user schedules cluster jobs from the reproducible packages the agent prepares.
- Update `PROGRESS.md` at research checkpoints with artifact paths, completed work, unresolved questions, and the next bounded step, so later sessions can continue without reconstructing the conversation.
